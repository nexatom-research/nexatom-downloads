# DLS Analysis

Dynamic Light Scattering (DLS) is a physics model that sits on top of the Multi-Tau Correlator (CORM) to determine the size distribution profile of small particles in suspension or polymers in solution.

When enabled, the C++ background thread automatically applies Cumulant expansion models to the CORM $g^{(2)}(\tau)$ decay curve, translating the correlation time directly into physical metrics like **Hydrodynamic Radius** and **Polydispersity Index (PDI)** based on the provided experimental conditions (temperature, viscosity, scattering angle).

### Function Reference

| Function | Parameters (In/Out) | Returns | Description |
| :--- | :--- | :--- | :--- |
| `nexatom_tt_enable_dls_analysis` | `[In] nexatom_tt_handle device`<br>`[In] bool enable` | `nexatom_error_code_t` | Arms the background C++ DLS physics solver. When active, `analysis_result.analysis_type` inside the CORM callback will be `1`. |
| `nexatom_tt_set_dls_experimental_conditions` | `[In] nexatom_tt_handle device`<br>`[In] double wavelength_nm`<br>`[In] double angle_deg`<br>`[In] double temp_c`<br>`[In] double vis_mPa_s`<br>`[In] double ref_index` | `nexatom_error_code_t` | Configures the physical constants (laser wavelength, scattering angle, fluid temperature, fluid viscosity, and refractive index) required by the Stokes-Einstein equation. |
| `nexatom_tt_set_dls_fit_range` | `[In] nexatom_tt_handle device`<br>`[In] uint32_t start_bin`<br>`[In] uint32_t end_bin` | `nexatom_error_code_t` | Restricts the Cumulant fit to a specific subset of the 80 CORM bins to avoid early-lag afterpulsing artifacts or late-lag baseline noise. |
| `nexatom_tt_enable_dls_cumulant_analysis` | `[In] nexatom_tt_handle device`<br>`[In] bool enable` | `nexatom_error_code_t` | Toggles the 2nd/3rd order Cumulant expansion solver (yielding PDI). |
| `nexatom_tt_set_dls_fitting_bounds` | `[In] nexatom_tt_handle device`<br>`[In] double* min_bounds`<br>`[In] double* max_bounds`<br>`[In] size_t count` | `nexatom_error_code_t` | Applies strict numerical constraints to the Levenberg-Marquardt solver to prevent unphysical outputs (e.g., negative diameters). |
| `nexatom_tt_set_dls_fitting_control` | `[In] nexatom_tt_handle device`<br>`[In] uint32_t max_iterations`<br>`[In] double tolerance` | `nexatom_error_code_t` | Tunes the internal solver termination criteria for a balance between speed and precision. |

### Data Structures: `nexatom_dls_analysis_result_t`

When DLS is enabled, the `nexatom_corm_callback_data_t` payload (dispatched via the callback registered in Section 7.8) will populate its nested `analysis_result.dls` struct with these computed physics parameters.

| Field | Type | Description |
| :--- | :--- | :--- |
| `hydrodynamic_radius_nm` | `float` | Estimated particle radius in nanometers via Stokes-Einstein. |
| `diffusion_coefficient` | `float` | Translational diffusion coefficient ($D_t$) in $cm^2/s$. |
| `z_average_diameter_nm` | `float` | Intensity-weighted mean size ($2 \times R_h$). |
| `polydispersity` | `float` | Dimensionless Polydispersity Index (PDI). Values $<0.1$ are highly monodisperse. |
| `mean_decay_rate` | `float` | First cumulant ($\Gamma$) characterizing the primary decay. |
| `variance` / `skewness` | `float` | Second ($\mu_2$) and third ($\mu_3$) cumulant terms representing distribution width and asymmetry. |

### C Example: Configuring a DLS Measurement

```c
// 1. Configure the physical constants for Water at 25°C
double wavelength = 632.8;   // HeNe laser (nm)
double angle = 90.0;         // 90-degree scattering
double temp_c = 25.0;        // Room temp
double viscosity = 0.89;     // Water viscosity (mPa*s)
double ref_index = 1.333;    // Water refractive index

nexatom_tt_set_dls_experimental_conditions(
    my_device, wavelength, angle, temp_c, viscosity, ref_index
);

// 2. Enable Cumulant Analysis (Standard approach)
nexatom_tt_enable_dls_cumulant_analysis(my_device, true);

// 3. Exclude the first 5 bins to avoid detector afterpulsing
nexatom_tt_set_dls_fit_range(my_device, 5, 80);

// 4. Activate the DLS solver pipeline
nexatom_tt_enable_dls_analysis(my_device, true);
```
